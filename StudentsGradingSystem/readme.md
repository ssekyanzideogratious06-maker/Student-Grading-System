#	The Student Grade System
The student grade system is a simple java console application development.
This project enables users to register the students,enter their marks, calculate grades and display student's results and their academic status.

##Project objectives
To demonstrate the use of java programming concepts like using the loops and conditional statements.

##Features
- Registering Students
- Entering student marks
- Validate marks between 0-100
- automatically calculate student grades
- display the student academic status
- interactive main menu
- exiting the system

##Java Concepts used

### 1.Ternary statement
this operator determines whether the student has passed of failed.

### 2.For loop
The for loop displays the registered students and their marks.

### 3.While loop
This ensures that the student marks entered in the system are within a valid range e.g between 0-100.

### 4.do while loop
This loop ensures that the main menu keeps on running until the user chooses the exit option in the system.

### 5.Menu options
1.Register students
2.Display student results
3.Exit

##Grading System

|Marks|  |Grade|
|80-100| | A   |
|70-79 | | B   |
|60-69|  | C   | 
|50-59|  | D   |
|0-49 |  | F   |


##How to run the program
1. Open eclipse
2. import or open the student grade project.
3. Open the student grading system menu
4. run the program
5. select an option from the student grading system menu
6. Follow the instructions displayed on the runtime screen.
